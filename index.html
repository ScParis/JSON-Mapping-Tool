Fundamentos do JMESPath

JMESPath é uma linguagem de consulta para JSON que permite extrair e transformar dados de forma poderosa e elegante.

O que é JMESPath?

JMESPath (JSON Matching Expression Path) é uma linguagem que permite:

  • Extrair dados específicos de estruturas JSON complexas
  • Filtrar elementos com base em condições
  • Transformar e reestruturar dados
  • Realizar cálculos e agregações
{
  "usuario": {
    "nome": "João Silva",
    "email": "joao@example.com",
    "idade": 30,
    "endereco": {
      "rua": "Rua das Flores",
      "cidade": "São Paulo"
    }
  }
}

Sintaxe Básica

Acesso a Propriedades

Use ponto (.) para acessar propriedades:

usuario.nome

Acesso a Arrays

Use colchetes [] para acessar elementos:

produtos[0].preco

Wildcard

Use * para selecionar todos os elementos:

usuarios[*].nome

Multi-seleção

Selecione múltiplos campos:

usuario.[nome, email]

Dicas Importantes

  • JMESPath é case-sensitive - respeite maiúsculas e minúsculas
  • Índices de arrays começam em 0, não em 1
  • Use aspas para strings com caracteres especiais
  • Combine operadores para criar consultas complexas

Filtrando Dados

Aprenda a filtrar elementos com base em condições específicas usando expressões poderosas.

Operadores de Comparação

Igualdade

usuarios[?ativo==true]

Maior/Menor

produtos[?preco>100]

Diferente

itens[?categoria!='eletronicos']

Contém

nomes[?contains(@, 'João')]

Operadores Lógicos

# AND lógico
usuarios[?ativo==true && idade>25]

# OR lógico  
produtos[?categoria=='eletronicos' || preco>500]

# NOT lógico
itens[?!contains(nome, 'teste')]

Atenção

Lembre-se de usar == para igualdade em JMESPath, não = como em muitas linguagens de programação.

Projeções e Transformações

Aprenda a reestruturar dados criando novos objetos e selecionando campos específicos.

Tipos de Projeções

Lista Projeção

Seleciona campos como array:

usuarios[*].[nome, email]

Hash Projeção

Cria novos objetos:

usuarios[*].{nome: nome, email: email}

Flatten Projeção

Achata arrays aninhados:

dados[][]

Pipe Projeção

Encadeia operações:

usuarios[?ativo==true] | [0]

Transformações Avançadas

# Concatenar strings
usuarios[*].{nomeCompleto: nome + ' ' + sobrenome}

# Expressões matemáticas
produtos[*].{precoComDesconto: preco * 0.9}

# Condicionais
itens[*].{status: estoque > 0 ? 'Disponível' : 'Esgotado'}

Funções Integradas

JMESPath oferece várias funções úteis para processamento de dados.

Funções de Agregação

sum()

Soma valores numéricos:

sum(vendas[*].valor)

length()

Conta elementos:

length(usuarios)

max()/min()

Valores máximo/mínimo:

max(produtos[*].preco)

avg()

Média aritmética:

avg(notas[*])

Funções de String

# Conversão de case
nomes[*].upper_case(@)
nomes[*].lower_case(@)

# Manipulação
split(texto, ' ')
join(array, ', ')
reverse(string)

# Verificação
contains(texto, 'buscar')
starts_with(texto, 'prefixo')
ends_with(texto, 'sufixo')

Funções de Array

# Ordenação
sort_by(produtos, &preco)
reverse(produtos)

# União e interseção
union(array1, array2)
difference(array1, array2)

Técnicas Avançadas

Combine tudo o que você aprendeu para criar consultas complexas e poderosas.

Pipe Operator

O operador | permite encadear múltiplas operações:

# Exemplo complexo: filtrar -> ordenar -> limitar
usuarios[?ativo==true] | sort_by(@, &idade) | [0:5]

# Transformação completa
vendas[?valor>100] | {total: sum([].valor), quantidade: length(@)}

Expressões Condicionais

# Ternário completo
produtos[*].{
    nome: nome,
    status: estoque > 10 ? 'Alto' : estoque > 0 ? 'Baixo' : 'Esgotado',
    precoFinal: categoria == 'premium' ? preco * 1.2 : preco
}

Consultas Aninhadas Complexas

# Extraindo dados de estruturas profundas
empresa.departamentos[*].funcionarios[?cargo=='gerente'].{nome: nome, salario: salario}

# Agregação múltipla
{
    totalVendas: sum(vendas[*].valor),
    mediaVendas: avg(vendas[*].valor),
    maiorVenda: max(vendas[*].valor),
    vendedores: length(vendas[*].vendedor | unique(@))
}
