Central de Ajuda & Manual

1. Visão Geral

O JSON Mapper é uma ferramenta para criar mapeamentos entre dois sistemas diferentes usando a linguagem de consulta JMESPath.

2. Como Mapear

Após carregar seus dados, clique em Gerar Mapeamento. O sistema lerá a estrutura do destino e abrirá o configurador.
